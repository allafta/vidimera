# Code of Conduct

This project records human decisions honestly; the same standard applies to how we treat
each other while building it.

## Expectations

Everyone participating in this project — in issues, pull requests, reviews, and any other
project space — is expected to:

- Be respectful. Disagree with ideas, not with people.
- Argue from evidence. This repository's whole discipline is claims with gates behind
  them; bring the same posture to discussion.
- Accept review gracefully, and give it constructively — review the change, state the
  problem concretely, and propose a path.
- Respect maintainers' decisions on scope. "Recorded, not built" is a normal outcome here,
  not a rejection of you.

## Unacceptable behavior

- Harassment, insults, or personal attacks, in any form.
- Discriminatory language or conduct.
- Publishing others' private information without explicit permission.
- Sustained disruption: bad-faith argument, sealioning, or re-litigating settled decisions
  without new evidence.

## Scope

This code applies in all project spaces, and when an individual is representing the project
in public.

## Reporting and enforcement

Report conduct issues to the maintainers privately. Since this repository publishes no
contact address, use GitHub's built-in reporting tools on the offending content, or open an
issue that says only "conduct — requesting private contact" and a maintainer will arrange a
private channel; do not put details of the incident in the public issue.

Maintainers will review every report, keep the reporter's identity confidential to the
extent the platform allows, and respond proportionately: correction, warning, temporary
restriction, or permanent ban from project spaces. Maintainers who fail to uphold this code
are subject to the same consequences.
